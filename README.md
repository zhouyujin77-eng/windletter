# 晚风邮局 | WINDLETTER

一款以书信、探索与情感叙事为核心的治愈系网页小游戏。

## 项目简介

《晚风邮局》是一款融合轻量经营、地图探索与互动叙事的网页游戏。

玩家将接手一间即将关闭的旧邮局，通过整理信件、探索小镇、帮助居民完成心愿，逐步恢复邮局的活力。

希望通过书信与故事，让玩家在游戏中感受人与人之间细腻而温暖的情感。

## 核心功能

- **邮局场景：** 展示邮局内部环境与交互元素。
- **信件系统：** 阅读信件，体验故事内容。
- **小镇探索：** 探索不同地点，发现人物与事件。
- **经营系统：** 管理金币、声望、满意度等数据。
- **设施升级：** 使用游戏资源升级邮局设施。
- **任务系统：** 完成指定任务并领取奖励。
- **数据记录：** 展示经营数据与游戏进度。
- **本地存档：** 保存游戏进度，支持继续体验。

## 技术栈

## 本地运行

1. 下载或克隆本项目。
2. 使用 VS Code 打开项目文件夹。
3. 使用 Live Server 启动 `index.html`。
4. 在浏览器中体验游戏。

## 项目亮点

- 独立完成网页小游戏的结构设计与功能开发。
- 使用 JavaScript 实现页面交互、游戏状态管理和本地存档。
- 使用 CSS 完成场景布局、视觉设计与响应式适配。
- 将轻量经营机制与互动叙事结合，形成完整的游戏体验。
